# 香港日月追視

第三款眼動遊戲：太陽及月亮依次沿上半圓由左至右移動，游標位於目標上才移動，離開即停。無需點擊或凝視等待。

公開網址：[香港日月追視](https://fox0310.github.io/steam-game/eye-gaze-games/day-night/)。[三款遊戲入口](https://fox0310.github.io/steam-game/eye-gaze-games/)。

## 老師操作

1. 選擇每段速度、太陽／月亮大小，以及 1–3 組日月。預設每段 40 秒、1 組。
2. 按「準備開始」啟用活動及聲音。學生以眼動儀移動瀏覽器游標，跟望太陽即可開始。
3. 太陽在右邊消失的同一幀，場景轉夜晚、左邊出現月亮及切換夜間音樂。月亮等待學生把游標移到它上面才移動。
4. 最後一段月亮到右邊完成，播放一次慶祝音效。多組活動每次交接均回到左邊等待重新跟望。
5. 「暫停」停止移動及音樂；「回到日間」重設活動。可隱藏老師設定、開啟專注畫面或全螢幕。

音樂在老師開始活動後持續循環。學生暫時望離目標時，目標停止，背景音樂繼續；老師暫停、切換到其他視窗、靜音或活動完成時，音樂停止。音量預設 25%，老師可調至 0–70%。

鍵盤：空白鍵開始／暫停；R 回到日間；Esc 離開專注畫面。老師設定獨立保存在本機。

## 場景與音樂

- 透明香港城市 PNG 由內置 ImageGen 生成，城市只佔畫面底部約五分之一。天空沒有雲、星、人物等裝飾，夜間使用同一城市剪影降低亮度。
- 太陽及月亮為簡單 SVG 圖形；只有學生跟望時才沿真正上半圓移動，沒有閃爍、浮動或其他裝飾動畫。
- 日間原創旋律：108 BPM，輕快撥奏音色，約 17.78 秒循環。
- 夜間原創旋律：64 BPM，柔和鐘聲及和弦墊音，30 秒循環。
- 兩段音樂由 `music.py` 原創作曲及合成為 WAV，不依賴外部音樂服務。音樂生成說明與完整場景提示詞見 [素材說明](assets/素材說明.md)。

## 本機與離線

```bash
npm run start:eye-gaze
npm run build:day-night
npm run test:day-night
npm run playtest:day-night
```

本機網址：`http://127.0.0.1:5220/eye-gaze-games/day-night/`。

直接雙擊 `香港日月追視_單檔版.html` 可離線使用；場景、SVG、兩段音樂、樣式及程式全部內嵌。修改程式或素材後，重新執行 `npm run build:day-night`。

重新合成音樂：`python3 eye-gaze-games/day-night/music.py`，然後重新建置單檔。

## 驗證與使用範圍

22 項 Chrome／WebKit 自動測試通過，涵蓋游標即行即停、靜止游標、同幀日夜交接、月亮重新獲取、兩段實際音訊解碼及切換、暫停／靜音、完成慶祝一次、多組活動、設定、窄螢幕、素材失敗及離線單檔。另有真正半圓與等速幾何檢查。

網站接收瀏覽器游標，不直接讀取眼動儀資料。Tobii／TD Control 需持續輸出游標位置；實機追視、音量及操作手感由老師試用。活動進度只代表路線完成程度。
