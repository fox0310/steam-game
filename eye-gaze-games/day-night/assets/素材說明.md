## 原創音樂

工具：Python 標準庫 `math`、`wave`、`array`；原創旋律與和弦譜保存在 `../music.py`。此環境沒有音樂生成 API，音樂由程式作曲及合成。

- `daytime.wav`：C 大調，108 BPM，八小節，17.778 秒。旋律每半拍一音，較明亮的撥奏／木琴音色及低音。正規化峰值約 0.44。
- `nighttime.wav`：64 BPM，八小節，30 秒。旋律每兩拍一音，柔和鐘聲與緩慢和弦墊音。正規化峰值約 0.30。
- 格式：22,050 Hz、單聲道、16-bit PCM WAV。尾音環繞到循環開頭，並在首尾各加 10 毫秒淡入／淡出，避免循環接點出現突變；供 Web Audio 循環播放。
- 終點慶祝聲：遊戲內 Web Audio 合成四音上行旋律，每次活動完成只播放一次。

重新生成：

```bash
python3 eye-gaze-games/day-night/music.py
npm run build:day-night
```

需求依據：FOX 指定日間音樂較歡樂、夜間音樂較柔和。沒有使用下載歌曲或第三方錄音。
