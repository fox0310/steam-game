# 交通工具追視

第二款眼動活動：游標在交通工具的白色目標框內立即移動，離開即停；不需點擊或等待凝視。老師按圖片選擇的士、貨車或黃色校巴，並選全圈、上半圈、下半圈。

## 使用

- 本機：`npm run start:eye-gaze`，開啟 `http://127.0.0.1:5220/eye-gaze-games/vehicles/`。
- 公開網址：[交通工具追視](https://fox0310.github.io/steam-game/eye-gaze-games/vehicles/)。
- 單檔：雙擊 `交通工具追視_單檔版.html`，三張車輛圖片、賽道及程式均已嵌入，無需連線。
- 老師先按「準備開始」啟用聲音。可調速度、目標大小、方向、圈／段數、音量、路線提示、專注畫面及全螢幕。
- 全圈繞橢圓一圈；半圈由一端到另一端。多段半圈以折返連續行駛。
- 更換車輛會暫停並回到起點，圖片完成載入後才可開始；選擇保存在本機，與運動場遊戲設定分開。
- 行駛時有輕柔節奏聲，停止時即靜音；到達終點只播放一次慶祝旋律。空白鍵開始／暫停，R 回起點。

## 實作與素材

- 沿用運動場遊戲的游標控制及 Web Audio，並載入其共用 CSS。新路線是真正橢圓，以弧長校正維持平順速度。
- `taxi.png`、`truck.png`、`schoolbus.png` 分別為 FOX 的 `的士_1.png`、`貨車_2.png`、`黃色校巴_3.png` 原樣副本；浮水印或棋盤背景保留。
- `oval-road.svg` 是程式繪製的簡潔公路，沒有外部素材或依賴。
- 網站只接收瀏覽器游標；TD Control 需持續將視線轉為游標。沒有直接連接 Tobii，進度不代表追視準確率；實機操作與音量由老師試用。
