# 圖字卡組句 · 我想說

第四款課堂遊戲。黑色背景配合大型原創圖字卡，讓學生點選簡單句子，向成人表達日常需要。

公開網址：https://fox0310.github.io/steam-game/eye-gaze-games/sentence-cards/

## iPad 操作

1. 用 Safari 開啟公開網址；橫向、直向均可操作。
2. 老師按「老師設定」，選擇一個情境及圖卡大小；需要時開啟句子提示。
3. 按「老師示範句子」，讓學生看排列、聽粵語，再按「自己試一試」。
4. 學生由左至右點選圖卡，不用拖拉。每按一張會讀出該詞。
5. 按「完成 · 說出句子」播放整句；學生亦可說話、指讀或展示圖卡。
6. 改動時可按已選圖卡刪除、按「退一張」或「重新排列」。「請幫我」保留現有句卡並讀出求助。

| 情境 | 句子 |
| --- | --- |
| 飲水 | 我＋想＋飲水 |
| 如廁 | 我＋想＋去＋廁所 |
| 休息 | 我＋想＋休息 |
| 求助 | 我＋需要＋幫忙 |

本版本為單一情境、指定句子的引導練習。順序不符時保留句卡並提示重新排列，沒有計分或限時。「請幫我」可在學生畫面及老師設定內使用。

「專注畫面」減少標題及頁尾。老師設定只存於目前瀏覽器；沒有帳戶、學生紀錄或資料上傳。聲音透過點選即時播放，靜音時仍可展示句子。請在實際 iPad 確認裝置音量及學生能理解的圖意。

## 素材及粵語

八張圖卡是本專案原創 SVG：我、想、去、飲水、廁所、需要、幫忙、休息。圖片配合文字，由老師示範詞義。

18 段 WAV 使用本機 macOS Sinji（`zh_HK`）語音生成，隨遊戲提供，不依賴 iPad 系統語音或雲端語音服務。來源、文字及生成方法見 `assets/README.md`。

## 本機及單檔

```bash
npm run start:eye-gaze
npm run build:sentence-cards
npm run test:sentence-cards
npm run playtest:sentence-cards
```

本機：http://127.0.0.1:5220/eye-gaze-games/sentence-cards/

`圖字卡組句_單檔版.html` 包含所有圖卡、程式及粵語音檔，供電腦瀏覽器離線開啟。iPad 請用 Safari 開啟 HTTPS 網址。

## 驗證

模型檢查涵蓋四個情境、順序、重複選卡、刪卡、示範及重設。45 項 Playwright 測試在 iPad 直向 WebKit、iPad 橫向 WebKit 及 Chrome 觸控模式通過，涵蓋觸控組句、實際音檔播放、靜音、求助、特大圖片、保存設定、失敗回退、單檔及小畫面排版。瀏覽器模擬測試不能替代實際 iPad 與學生試用。
