# 分類配對 · 找一找

第五款課堂遊戲，以空白鍵／拍掣辨認動物、植物及死物。黑色背景、大型簡潔圖片及粵語解說。

公開網址：https://fox0310.github.io/steam-game/eye-gaze-games/classification/

## 操作

1. 老師按「老師設定」，選學生要分辨的目標：動物、植物或死物。
2. 在設定視窗按「開始遊戲」，視窗關閉後開始。九張圖每 5 秒切換，包含每類三張。
3. 學生看到目標圖片，按空白鍵或拍掣；也可點「這是目標」大按鈕。
4. 正確時聽「答對了」、物件名稱、類別和辨認特徵，再播放獎勵音效。錯誤時說出真正類別、特徵，鼓勵下一張再試。
5. 依 FOX 選擇，答題後停留本圖，播完約 7 秒完整講解才換下一張，恢復每 5 秒換圖。
6. 拍掣需設定為 Space／空白鍵輸入，按下後放開；每圖只答一次，按住跨圖或連按不會重複觸發。

學生畫面只保留分類目標、大圖片、物件名稱及作答按鈕；答題期間才顯示辨認特徵，換圖時清除。開始、重新開始、聽目標、音量、靜音及返回遊戲室全部放入「老師設定」，按下才彈出。關閉設定不會自行開始，需由老師按「開始遊戲／繼續遊戲」。設定只保存在本機瀏覽器；切換視窗或離開頁面也會暫停。

## 教學目標與圖片

| 類別 | 圖片 | 學生辨認特徵 |
| --- | --- | --- |
| 動物 | 貓、狗、小鳥 | 會成長、活動和叫，對外界刺激有反應。 |
| 植物 | 花朵、樹木、仙人掌 | 會成長，不會像動物自行走動或發出叫聲。 |
| 死物 | 玩具車、皮球、椅子 | 不會成長，也不會自己活動或回應呼喚。 |

每張圖片有各自的答對及答錯音檔，會讀出具體物件名稱及該類別特徵。錯誤提示不以懲罰聲處理，保留圖片讓學生聽說明。

植物並非「沒有反應」：會對光、觸碰等刺激有反應，部分反應較慢；老師設定內有此說明。依 [RHS 植物如何感應環境](https://www.rhs.org.uk/advice/understanding-plants/how-plants-sense-the-environment) 及 [Kew 含羞草介紹](https://powo.science.kew.org/taxon/urn:lsid:ipni.org:names:313242-2/general-information) 核對。以上動物聲音特徵限於本遊戲的貓、狗、小鳥；不能把「會叫」當成所有動物的必要條件。死物可被人移動，電子玩具也可發聲，所以需合併成長及自主活動等特徵教學。

本遊戲是引導辨認練習，不將按掣次數或未按視為診斷／學習準確率。

## 聲音與失敗回退

- 21 段內置粵語 WAV：三個目標提示、九段答對講解及九段錯誤講解。每段答對音檔最後含原創三音獎勵。
- 使用 macOS Sinji `zh_HK`，逐字稿及生成程式在 `assets/`。不依賴瀏覽器語音或雲端服務。
- 靜音／音量零時顯示圖片特徵 7 秒，再換圖。
- 音訊失敗時停留本圖及文字，老師可按「繼續看圖片」；包括音訊開始後才失敗的回退。
- 圖片未能載入時禁止開始，提示重新載入。

## 本機、離線與驗證

```bash
npm run start:eye-gaze
npm run build:classification
npm run test:classification
npm run playtest:classification
```

本機：http://127.0.0.1:5220/eye-gaze-games/classification/

電腦可直接開 `分類配對_單檔版.html`；所有圖片、程式及音檔已內嵌。iPad 使用 Safari 開啟 HTTPS 網址，透過外接空白鍵拍掣或觸控大按鈕操作。

模型自檢及 60 項 Chrome／iPad 橫直向 WebKit 瀏覽器測試通過，覆蓋五秒切圖、三類正誤判斷、逐圖片音檔、完整講解停留、按住／重複鍵、暫停／設定、靜音、失敗回退、單檔及響應式畫面。實際拍掣映射、裝置音量及學生對圖意的理解仍需課堂試用。
