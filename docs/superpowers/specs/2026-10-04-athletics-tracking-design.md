# 運動場追視遊戲設計

FOX 已要求開始製作第一款遊戲：使用老師提供的運動場背景及跑步運動員，支援全圈、上半圈、下半圈追視。

- 教學目的：學生用視線跟隨單一移動人物；老師觀察。FOX 補充：游標在人物內即移動、離開即停止，無點擊或凝視延遲。以游標作操作輸入，不宣稱它是原始視線紀錄。
- 素材：田徑運動場_4.png 與跑步運動員_1.png 的 PNG 副本，原檔不改動。人物放在高對比圓形目標內，維持直立、隨方向轉向。
- 路線：沿背景的跑道，包括直線及兩端弧線；全圈完成一圈，上半圈／下半圈從左端沿指定半邊到右端；可選反方向。到終點停下並慶祝，沒有瞬間跳回起點。
- 老師控制：準備開始／暫停、回起點、全圈／上半圈／下半圈、圈／段數、速度、人物大小、方向、路線提示、專注畫面、全螢幕。
- 時間：預設一圈或一段半圈需實際追視移動 40 秒，可調 16–80 秒；停止追視時進度與移動時間凍結，可選 1–3 圈／段；人物大小 6–12% 場地寬度，預設 8%。切換路線／方向會暫停並回起點。
- 初次載入不自動移動。老師按準備開始啟用 Web Audio，學生游標進入人物後立即移動。鞋步節奏只在移動時播放，完成播放一次慶祝旋律，可靜音及調音量。失焦／背景分頁／開啟設定會暫停；老師自行恢復。保持運動場比例，人物不越出畫面。
- 設定只存在本機。對損壞的 localStorage、無法全螢幕或載圖失敗提供正常回退；載圖失敗禁用開始。
- 學生專注畫面隱藏多餘控制，保留老師可用的暫停及設定；空白鍵暫停／開始、Esc 離開專注、R 回起點，表單操作不截取快捷鍵。
- 原生 DOM／SVG／JavaScript，無新依賴，保留既有遊戲與未提交修改。
- 網站自包含於 eye-gaze-games/；提供可直接雙擊的單檔 HTML，及 GitHub Pages 打包腳本。第一版先供本機試用；FOX 其後已授權上載 GitHub Pages。
- 驗收：三路線邊界、閉環／平滑返程、速度與縮放；瀏覽器實測開始暫停／設定／載圖／手機平板適應／單檔 HTML；截圖核對。
- Tobii／TD Control 實機追視舒適度及學生表現須由老師課堂驗證。
